See the call.

A tiny bookmarklet that shows a separate audio lane for every Nextcloud Talk participant, tapped from incoming WebRTC tracks.

Install

Preparing bookmarklet…

  1. Show your browser’s bookmarks bar.
  2. Drag Talk waveforms onto the bar. You can also click it to copy, then create a bookmark and paste into its URL field.
  3. Open a Nextcloud Talk call and click the bookmark before joining. Loading it later still uses media-element fallbacks.
  4. Each participant gets an overlay. Click its mode button to cycle views; collapse the toolbar to hide all overlays, then use the small Talk waveforms button to reopen them.
  • Live waveform
  • 15-second level history
  • Live spectrum
  • Scrolling spectrogram
